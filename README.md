# Enterprise-Threat-Hunting-Lab-using-Wazuh-SIEM
A hands-on Enterprise Threat Hunting Lab built using Wazuh SIEM, Windows 11 Endpoint, and Sysmon for endpoint visibility and threat detection.  This project demonstrates endpoint monitoring, Windows event collection, MITRE ATT&amp;CK mapping, vulnerability assessment, security configuration assessment, and threat hunting using Wazuh.
